# Circuit Fault Simulation Engine

High-performance circuit simulation engine for testing fault propagation.

## Features
- Real-time simulation loop.
- JSON schema-based circuit definition.
- Hardware-accelerated canvas rendering.
- State persistence (Import/Export).

## Quick Start
- Open `index.html` in a modern browser.
- Use toolbar to add components (AND, OR, NOT, FLIP-FLOP).
- Press `Ctrl+S` to export circuit state.
