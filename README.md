# Circuit Fault Simulation Engine

High-performance circuit simulation engine for testing fault propagation, live signal tracing, and stuck-at fault injection.

## Features
- Real-time simulation loop with play/pause and step controls.
- JSON schema-based circuit definition with robust serialization and import/export.
- Hardware-accelerated HTML5 canvas rendering with glow effects and real-time wire propagation.
- Interactive fault injection (Stuck-at-0, Stuck-at-1) for fault testing.
- Component library (AND, OR, NOT, FLIP-FLOP, INPUT, OUTPUT).

## Quick Start
- Open `index.html` in a modern browser.
- Use the top toolbar to add components and toggle simulation state.
- Press `Ctrl+S` to export circuit state or load existing JSON configurations.
